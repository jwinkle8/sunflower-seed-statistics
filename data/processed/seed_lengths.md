# Datasheet: `seed_lengths.csv` (processed)

Metadata for the processed sunflower seed kernel measurements, following the *Datasheets for Datasets* framework
(Gebru et al., 2018). This file is generated by `src/clean.py` from `data/raw/seed_lengths.csv` and must not be
edited by hand. For motivation, acquisition, sampling, and measurement details, see the raw datasheet,
[`data/raw/seed_lengths.md`](../raw/seed_lengths.md). This datasheet covers only what changed.

## Composition

- **Instances:** Each row is one sunflower seed kernel, in the same order as the raw file.
- **Size (current file):** 1608 rows, 5 columns, no missing values. No rows have been removed or changed.

| `product` | `state` | Bags | Rows |
|---|---|---|---|
| `BIGS` | `pa` | `bigs_1`, `bigs_2`, `bigs_3` | 402 |
| `BIGS` | `fl` | `bigs_4`, `bigs_5`, `bigs_6` | 402 |
| `DAVID` | `pa` | `david_1` | 402 |
| `DAVID` | `fl` | `david_2` | 402 |

### Data dictionary

| Column | Type | Description | Units / allowed values |
|---|---|---|---|
| `seed_length` | float | Length of the shelled kernel, unchanged from raw | mm, recorded to 0.1 mm; observed range 8.4–15.9 |
| `bag` | string | The bag the kernel was sampled from, unchanged from raw | `bigs_1`–`bigs_6`, `david_1`, `david_2` |
| `state` | string | US state where the bag was purchased, unchanged from raw | `pa`, `fl` |
| `product` | string | **Derived.** Product, from the prefix of `bag` | `BIGS` (BIGS Dill Pickle), `DAVID` (DAVID Original Jumbo) |
| `outlier_iqr` | bool | **Derived.** `True` if `seed_length` is outside the 1.5 × IQR fences computed within its `product` | `True`, `False` |

## Preprocessing

Run `python src/clean.py` to regenerate this file. Each run also writes a full cleaning report,
`seed_lengths_cleaning_report_<YYYY-MM-DD_HHMMSS>.txt`, to this folder, recording the run time, git commit, and
every check result. The most recent report matches the current CSV. Steps, in order:

1. **Quality checks on the full dataset:**
   - **Duplicates:** 1,253 duplicated rows reported. This is expected and is not evidence of duplicate entries:
     rows have no seed id, and lengths are recorded to 0.1 mm, so distinct seeds from the same bag often have
     identical rows.
   - **Missing values:** none.
   - **Inconsistent values:** none. Checks: `seed_length` is numeric and a multiple of 0.1 mm; `state` is `pa` or
     `fl`; `bag` matches `bigs_N` / `david_N`; each bag is recorded in exactly one state.
   - **Expected counts** asserted: 134 seeds per BIGS bag, 402 per DAVID bag.
2. **Derived `product`** from the bag prefix; asserted 804 seeds per product.
3. **Outliers flagged, not removed,** using 1.5 × IQR fences within each product. 24 rows flagged:

   | Product | Fences (mm) | Flagged |
   |---|---|---|
   | BIGS | 8.95–14.15 | 16 |
   | DAVID | 8.55–14.55 | 8 |

## Known issues

- **Possible measurement difference between collection sessions.** Florida readings are about 0.15–0.17 mm lower
  than Pennsylvania readings for both products (medians 11.4 vs. 11.6 mm). State, collector, and caliper
  are confounded (the Pittsburgh caliper in PA, the ZYLTech caliper with ±0.2 mm stated accuracy in FL), so the cause can't be separated.
  Each state measured 402 seeds of each product, so a session shift affects BIGS and DAVID equally.
- **Clustering.** Kernels within a bag are not independent; DAVID has one bag per state, so product and bag are
  confounded for DAVID.

## Uses

- **Intended use:** Input to `src/analyze.py` for the two-sided Mann-Whitney U comparison of BIGS vs. DAVID
  kernel lengths.
- **Using the outlier flag:** `outlier_iqr` is informational. Filtering on it is an analysis decision and must be
  documented; flagged values look like genuinely small or large kernels.
