# Do BIGS and DAVID sunflower kernels differ in length?

Project 2 for Duke University AIPI 510: Data Sourcing (Fall 2026)

Authors: [@calebbmcneill](https://github.com/calebbmcneill) (Caleb McNeill),
[@jwinkle8](https://github.com/jwinkle8) (Justin Winkler).

We designed and ran an experiment comparing the kernel lengths of two competing sunflower seed products, **BIGS Dill
Pickle** and **DAVID Original Jumbo**. Seeds were drawn at random from retail bags bought in Pennsylvania and Florida,
hulled, and measured with digital calipers to the nearest 0.1 mm.

## Study design

| | |
|---|---|
| **Null Hypothesis (H<sub>0</sub>)** | The two products' kernel length distributions are equal, P(BIGS > DAVID) = 0.5. |
| **Alternative Hypothesis (H<sub>1</sub>)** | They are not equal (two-sided). |
| **Significance level** | α = 0.05, fixed before data collection |
| **Test** | Mann-Whitney U, chosen after pilot assumption checks showed non-normal, right-skewed lengths in both products |
| **Pilot** | 45 seeds per product, used for assumption checks and the effect-size estimate |
| **Main study** | 1,608 seeds: 804 per product, half from Pennsylvania bags and half from Florida bags |
| **Power** | About 25% for the pilot's effect (relative effect 0.519); about 80% for a 0.1 mm shift. The study is reported as underpowered for the effect size estimated during the pilot study. |

Full details, including limitations, are in the written report.

## Reproducing the analysis

### 1. Set up the environment

The project requires Python 3.10 or later.

```bash
git clone https://github.com/jwinkle8/aipi-proj2.git
cd aipi-proj2
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Run the scripts in order

Run each script from the repository root. Each one reads only files committed to the repo or produced by an earlier step.

| Step | Command | Reads | Writes |
|---|---|---|---|
| 1. Pilot assumption checks | `python src/check_assumptions.py` | `data/pilot/pilot.csv` | `figures/pilot/` (histograms, Q-Q plots, measurement order); test results to the terminal |
| 2. Power analysis | `python src/power_analysis.py` | `data/pilot/pilot.csv` | `figures/pilot/power_curve.png`; power shown in the plot legend |
| 3. Data cleaning | `python src/clean.py` | `data/raw/seed_lengths.csv` | `data/processed/seed_lengths.csv`, a timestamped cleaning report, `figures/cleaning/` |
| 4. Statistical analysis | `python src/analyze.py` | `data/processed/seed_lengths.csv` | `data/final/` (final data, results, and a timestamped analysis report), `figures/analysis/` |

Notes:
- `power_analysis.py` opens the power curve in a window after saving it. Close the window to let the script finish.
- `clean.py` and `analyze.py` write new reports named `seed_lengths_cleaning_report_<YYYY-MM-DD_HHMMSS>.txt` `analysis_report_<YYYY-MM-DD_HHMMSS>.txt` on every run. Each
  report records the git commit it ran from, so results can be traced to the exact code that produced them.
- Rerunning a step overwrites its outputs. If you rerun steps after changing code or data, check the git diff of the
  outputs before committing.

## Data provenance

- **Sourcing:** six BIGS Dill Pickle bags and two DAVID Original Jumbo bags, bought at Walmart stores in Pennsylvania and
  Florida on October 19, 2026. Measured October 23–24, 2026.
- **Measurement:** each author measured the bags from their own state, using a different digital caliper. Instruments,
  the sampling procedure, and the definition of kernel length are documented in
  [data/raw/seed_lengths.md](data/raw/seed_lengths.md).
- **Corrections:** one value was corrected in the raw file after a digit was lost during data entry (1.9 mm became 11.9 mm,
  commit `a3d0c3d`). This was discovered during data cleaning procedures. No other recorded values have been changed.
